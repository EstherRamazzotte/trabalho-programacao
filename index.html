Introdução

O que é JavaScript?

Criado em 1995 por Brendan Eich em apenas dez dias, o JavaScript nasceu para dar interatividade ao navegador — e hoje é uma das linguagens mais usadas do planeta. Junto com o HTML (a estrutura) e o CSS (o estilo), ele forma o terceiro pilar da web: o comportamento.

Com JavaScript, uma página reage a cliques, valida formulários, busca dados, anima elementos e muito mais. E ele saiu do navegador: com o Node.js roda em servidores, aplicativos e até robôs. Tudo o que você vê funcionando nesta página — inclusive os botões de executar — é JavaScript puro.

1995 ano de criação, na Netscape
~98% dos sites do mundo usam JavaScript
3º pilar da web, ao lado de HTML e CSS
